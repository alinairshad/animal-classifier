🐾 A deep learning experiment · 10 animals

Can a computer tell a cat from a chicken?

I trained two models on the same 7,000 animal photos: a plain neural network (an MLP) that sees a picture as one long list of pixels, and a Teachable Machine model that borrows a pre-trained brain. Same epochs, same batch size, same learning rate. Then I tested both on 1,500 photos they had never seen.

So why the huge gap?

An MLP turns the photo into one long list of numbers, so it forgets which pixels are neighbours. To it, ears, legs and wings are just scattered dots, and it ends up guessing from colours and backgrounds. Teachable Machine starts from a convolutional network that already learned edges, textures and object parts from millions of photos, and only has to learn which animal is which. That trick is called transfer learning.
